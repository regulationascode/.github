# Regulation as Code

Open infrastructure for clear, executable, and auditable financial reporting controls.

Our first project is [Regulation as Code Studio](https://github.com/regulationascode/regulation_as_code), a local public preview that traces a reporting example from cited source and human review through deterministic validation, report preview, and evidence. It includes three complete synthetic examples.

Start with the [quickstart](https://github.com/regulationascode/regulation_as_code/blob/main/docs/quickstart.md), then read the [bank adoption guide](https://github.com/regulationascode/regulation_as_code/blob/main/docs/bank_adoption.md). Contributions and reporting profile proposals are welcome through the project repository.

The project is an early preview. Its examples are not official filing rules, and this organization has no regulator, bank, or foundation endorsement.
